# Single-Player-Poker
A singleplayer poker like game and a programming challenge.

**Rules:**
You name a subset of cards that you want and the dealer repeatedly draws a card. If the card is one you wanted, you take the card. Otherwise the dealer takes the card. After you take a card, you specify another subset of cards that you want and the dealer will draw cards again. Once you have 5 cards and the dealer has at least 8, your hand is compared to the dealer's best hand and the higher one wins. Write a function that can returns an array of all the cards that you are willing to pick up. The goal is to achieve the highest winrate possible.
